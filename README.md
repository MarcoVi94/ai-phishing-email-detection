# Analysis of Machine Learning-Based Phishing Detection Systems Against AI-Generated Emails

## Project Overview

This project investigates the effectiveness of machine learning-based classifiers in detecting phishing emails, with a particular focus on emails generated by Artificial Intelligence.

The project involves the development, training, and evaluation of two classification models, analysing their performance on different datasets and assessing their ability to generalize to AI-generated phishing emails.

## Project Structure

- **`main.py`** – Main script responsible for loading the selected dataset, preprocessing the data, splitting it into training and test sets, converting email text into numerical representations using TF-IDF, training the classifiers, and evaluating their performance. Trained models and TF-IDF vectorizers are saved for subsequent use.
- **`mlp.py`** – Contains the implementation and training procedures for the Multi-Layer Perceptron (MLP) classifier.
- **`logistic_regression.py`** – Contains the implementation and training procedures for the Logistic Regression classifier.
- **`cross_dataset.py`** – Handles cross-dataset experiments to evaluate model generalization across different datasets.
- **`generate_ai_dataset.py`** – Script used to generate the dataset of AI-generated emails.
- **`test_ai_dataset/`** – Contains scripts used to evaluate the classifiers on the dataset of AI-generated emails.
- **`datasets/`** – Stores the datasets used throughout the experiments.
- **`models/`** – Stores the trained classification models.
- **`vectorizers/`** – Stores the trained TF-IDF vectorizers.

Additional scripts support data preparation and the translation of AI-generated emails from Italian into English while preserving their original labels.

## Methodology

The experimental workflow includes data preprocessing, TF-IDF text vectorization, model training, performance evaluation, and cross-dataset testing. Additional experiments are conducted using AI-generated phishing emails to analyse classifier performance in this specific context.

## Objectives

- Evaluate the performance of machine learning models in phishing email detection.
- Investigate model generalization across different datasets.
- Assess the effectiveness of classifiers in detecting AI-generated phishing emails.

## Datasets

The datasets used for training and evaluation are not included in this repository due to file size limitations. They can be downloaded from Kaggle:

- **Phishing Email Dataset** – Naser Abdullah Alam  
  https://www.kaggle.com/datasets/naserabdullahalam/phishing-email-dataset  
  File used: `phishing_email.csv`

- **AVN Phishing Email Classification Dataset** – AVN BlueFox  
  https://www.kaggle.com/datasets/avnbluefox/avn-phishing-email-classification-dataset  
  File used: `AVN_Corpus.csv`

### AI-Generated Email Datasets

The following datasets contain email samples generated using artificial intelligence for this project:

- `ai_email.csv` – AI-generated email samples in Italian.
- `ai_email_en.csv` – AI-generated email samples in English.

These datasets were used to evaluate the models' ability to detect phishing emails generated by AI in both languages.
